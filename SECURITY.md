# Security

This project measures Linux PMU counters. Incorrect or noisy measurements are
**not** security issues; file a bug instead.

If you find a vulnerability in the code (for example path handling that could
overwrite unexpected files when given a malicious path), do **not** open a
public issue. Use GitHub’s private vulnerability reporting on this repository,
or email the owner listed on the GitHub profile.

Please include a reproduction that does not require secret host credentials.
